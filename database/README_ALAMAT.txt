FITUR ALAMAT PENGGUNA

1. Import database/alamat_pengguna.sql ke database ronggolawe_batik satu kali.
2. Setelah itu user dapat membuka menu Alamat.
3. User dapat menyimpan lebih dari 2 alamat, mengedit, menghapus, dan menentukan alamat utama.
4. Checkout hanya memilih alamat tersimpan; ongkir otomatis mengikuti kota dari alamat tersebut.
5. Metode pembayaran dipilih saat checkout dan tidak lagi memiliki tombol "Simpan Metode" di halaman pembayaran.
